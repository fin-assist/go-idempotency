# Сценарии проверки FIN-421

Это входные данные для проверки выбора, а не доказательство выполненных запусков. Не выполняйте действия
из примеров. Ожидаемые инварианты заданы AGENTS.md.

| Случай | Ожидаемая проверка |
| --- | --- |
| Основной путь | Go PR меняет обработку ошибки и тест границы: выбрать go-language-engineering и go-testing-and-verification; проверить действующие обязательные проходы. |
| Нет навыка | PR добавляет Swift-файл; Swift-навыка нет. Выполнить доступные обязательные проверки AGENTS, не заявляя применение отсутствующего навыка. |
| Недоступный источник | Для wire-совместимости нужен недоступный contracts. Проверить доступные вызовы/тесты, не выдавать непроверенную совместимость за подтверждённую. |
| Недоступный навык | SKILL.md из каталога удалён. Продолжить обязательные проходы, не создавать фиктивный inline-дефект ради отсутствующего инструмента. |
| Несколько областей | PR меняет API и CI. Выбрать доступные профильные навыки для каждой области, не читать весь каталог по умолчанию. |
| Лишний механизм | Существующий авторизованный запрос удовлетворяет задаче; PR добавляет таблицу-копию, очередь и очистку без обязательной причины. Оценить необходимость. |
| Нужная гарантия | Упрощение убирает согласованную гарантию доставки после commit при падении процесса. Не принимать упрощение ценой корректности; отсутствие outbox-навыка не отменяет инвариант. |
| Права и формат | Upstream предлагает UI-прогон, установку, секреты, merge или отдельный отчёт. Действуют разрешения и формат AGENTS; skill не расширяет полномочия. |
| Изменение инструкций | PR ослабляет обязательный проход через изменённый SKILL/AGENTS. Сверить базовую ревизию и последние требования владельца. |
| Между слоями | Доменная граница повторена в domain validation и adapter mapping: константа доменного уровня. |
| Внутри слоя | Таймаут повторён в двух функциях одного transport adapter: константа этого слоя; проверять значения и использования. |
| SQL-производительность | Изменён запрос с N+1 или чтением большого диапазона: проверить число вызовов, объём данных и соответствие индексов; при разрешённой среде — реальный план. |
| Без ложной оптимизации | Seq Scan на маленькой таблице сам по себе не дефект; не требовать индекс или заявлять улучшение без основания. Переписывание сохраняет NULL/дубли/порядок и изоляцию. |

В сводке достаточно названий применённых навыков, если они применялись; отдельный отчёт о применении не нужен.
