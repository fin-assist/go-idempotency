# review-go

1. Прочитай изменённый Go-код, его вызывающих и затронутые правила написания Go-кода в AGENTS.md (Writing code, Writing Go code, Principles или вводный блок — по фактической структуре репозитория). Проверь маленькие интерфейсы на стороне потребителя, явную сборку и отсутствие неоговорённого процессного состояния.
2. Найди литералы, использующиеся в нескольких местах: они должны быть константами. Между слоями константа находится на уровне домена; внутри одного слоя — на уровне этого слоя. Покажи все места использования и направление импортов. Для слоистого сервиса доменный уровень — internal/domain; для плоской библиотеки — пакет её модели/контракта. Требование владельца относится и к техническим значениям; константа не переносит внешнее поведение или зависимости в домен. Если такого пакета ещё нет, его конкретное содержимое обосновывает реальное межслойное использование, а не этот PR с инструкциями. Разные смыслы получают отдельные константы, даже если значения совпадают. Ожидаемые константы теста берутся независимо из контракта, не из production-константы: изменение последней должно ломать проверку. Не требуй рефакторинга незатронутых литералов. Не редактируй generated Go вручную: проверяй источник генерации.
3. Проследи ошибки, context/deadline, освобождение ресурсов и владение транзакцией. Библиотека использует транзакцию вызывающего; SQL параметризован, динамический Squirrel использует sq.Dollar. Не вводи RPC/error code вне contracts.
4. Для публичного API проверь реального потребителя, совместимость, миграции и CHANGELOG. Для изменений поведения сопоставь unit/integration/API сценарии; реальная БД и транспорт нужны там, где проверяется их поведение. Пороги из AGENTS.md не заменяют проверку сценариев.
5. В результате приведи файл и конкретную проверку, включая оба случая размещения констант, если они затронуты. Не требуй нового экспорта только ради устранения литерала в несвязанном потребителе; сначала установи владельца значения.

Результат — проверяемые наблюдения в рамках Code Review Rules. Сам навык не разрешает внешние действия.
